# User guide

- [Build a release](release.md): from a dump's date to published datasets, with the

- [Monitor and resume](monitoring.md): reading progress from the files on disk,

- [Tuning](tuning.md): how many chunks to process at once, group sizes, and disk limits.
- [Performance](performance.md): measured timings of the release 20260928.
- [The philippesaade build](source-copy.md): the earlier build from the
  `philippesaade/wikidata` Parquet copy, still supported.
