# 2026-09-30: Demo scripts on the local copy

## Current State

### Layout

- Each demo is a standalone script in `demos/` reading a local copy of the six datasets (`--data`, default `hub/`), and most have a shell runner beside it writing to `demos/output/<name>.stdout` (demos/divisions.sh, demos/timeline.sh, demos/bbc_things.sh).
- `demos/classes.py` holds the helpers shared by the class demos: `Local` (claims with deprecated statements left out, label and description lookups falling back from the chosen language to `mul` to `en`, Wikipedia counts from the `links` folders named `[a-z_]+wiki` minus `NOT_WIKIPEDIA`), `subclasses` (one pass over the P279 edges, then a breadth-first walk) and `members` (one pass over P31).
- Property ids (`P…`) sort between lexemes and items in the sorted claims, so a filter `id >= "P" and id < "Q"` reads only the first row groups (demos/news_ids.py, demos/export_bearers.py).
- Lookups of known ids read only the row groups that can hold them; questions about values (who has P31 = X) take a pass over the claims filtered on `property` (demos/classes.py).

### Demos

- demos/item.py prints one item in one language; demos/ancestors.py walks P22/P25 in batches of ids per generation.
- demos/divisions.py tabulates a country's P150 divisions with ranks, qualifiers and units (demos/output/divisions*.stdout for Q30, Q142, Q183).
- demos/timeline.py lays out an item's dated statements and its population (P1082) as a bar chart (demos/output/timeline*.stdout).
- demos/wikiprojects.py collects P5008/P6104 WikiProject links, leaving out items with a numeric value (P1181).
- demos/concepts.py and demos/algorithms.py list the members of mathematical concept (Q24034552) and algorithm (Q8366) through their subclass trees.
- demos/properties.py ranks properties by the entities holding them, overall and among the items in the most Wikipedias.
- demos/bearers.py describes the items bearing one or more properties (kinds, best known, a random sample, over-represented properties by lift, `--pattern` grouping of values), run for BBC Things (P1617), Google Knowledge Graph (P2671), WordNet 3.1 (P8814) and BBC News topic (P6200) ids.
- demos/news_ids.py selects the 81 properties that are instances of "Wikidata property to identify news website topics" (Q105946994) — earlier versions matching descriptions and formatter URLs took in article, author and issue ids (demos/output/news_ids.stdout).
- demos/export_bearers.py writes the bearers of some properties to Parquet for Embedding Atlas, with `--column`, `--without` and `--not-a` (demos/news_topics_export.sh, demos/formulas_export.sh, demos/news_topics_view.sh, demos/formulas_view.sh).
- demos/formulas_export.sh leaves out instances of integer (Q12503) and of prime number (Q49008) as two classes — the statement "prime number subclass of odd number" has rank deprecated, so prime number falls outside the subclass tree of integer once deprecated statements are left out, and 105,262 items described "prime number" stayed in until Q49008 was named.
- The `.parquet` outputs in demos/output are gitignored (`*.parquet` in .gitignore) and the `.stdout` outputs are committed.
